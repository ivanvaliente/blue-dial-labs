Listings, feeds, and catalogs rarely describe the same watch the same way. WristAtlas is Blue Dial Labs' canonical identity product for resolving supported evidence to a stable Brand → Collection → Model → Reference → Variant hierarchy while keeping provenance and uncertainty visible.

The identity problem

One watch can arrive as several different records.

Reference punctuation changes. Model names get shortened. Source-specific identifiers do not travel across systems. Variant detail may be incomplete or contradictory. Without a stable identity layer, downstream software has to reconcile the same product repeatedly.

01 / Formatting

Equivalent references do not always look equivalent.

T1374071104100↔T137.407.11.041.00

A compact source string and a punctuated manufacturer reference can represent the same canonical watch.

02 / Fragmentation

Source records are evidence, not shared identity.

Listings and feeds may carry their own titles, SKUs, aliases, and taxonomy. Those values remain useful evidence, but they are not a durable cross-source key by themselves.

03 / Uncertainty

Ambiguity should not disappear downstream.

A plausible reference match is different from a resolved variant, physical watch, authenticity judgment, or seller assessment. WristAtlas keeps those boundaries explicit.

Stable identity

Canonical values are not copied listing titles.

Source wording can change while the canonical reference remains the same identity anchor.

Evidence lineage

Normalization should not erase provenance.

WristAtlas is designed to distinguish what a source reported from the canonical interpretation built from that evidence.

Confidence boundary

Unknown stays unknown.

A resolved reference does not require WristAtlas to invent a variant or silently upgrade incomplete evidence into stronger certainty.

External identity use

Potential future uses include catalog reconciliation, reference lookup, external-identifier mapping, professional data feeds, or API access. None is announced as a public production service today.

Downstream value

Stable identity makes better data work possible.

WristAtlas is not valuable because it adds another watch database. Its job is to give supported evidence a durable identity so comparisons, history, and downstream decisions can refer to the same product consistently.

01

Cross-source continuity

Different source strings can converge on one canonical reference without discarding the original evidence.

02

Reference-level history

Market observations can attach to a durable product identity rather than temporary listing wording.

03

Like-for-like comparison

Downstream systems can determine whether evidence belongs to the same reference before attempting economic or product comparison.

04

Explicit uncertainty

Unresolved variants and lower-confidence identity evidence can remain visible instead of silently becoming authoritative facts.

Internal first, external later

Built for WristOwl first. Designed so the identity layer can stand on its own later.

WristAtlas exists today because Blue Dial Labs needs canonical watch identity for its collector decision product. Keeping that capability product-neutral preserves the option for broader use without forcing a second commercial operating surface before external demand is validated.
